Configuracao do servidor

Falta conectar ao Supabase. Abra este arquivo (index.html) num editor de texto e cole, no topo do script, a URL e a chave do seu projeto:

const SUPABASE_URL = 'https://SEU-PROJETO.supabase.co';
const SUPABASE_ANON_KEY = 'sua-chave-anon-public';

Voce encontra os dois valores no painel do Supabase em Project Settings > API. Antes, rode o arquivo supabase_setup.sql no SQL Editor para criar as tabelas e os dados de teste. O passo a passo completo esta no README.
